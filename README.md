# Awesome Agentic Commerce

A curated tracker of companies building the agentic commerce stack — who has a real agentic strategy, who's shipping, and who's still watching.

This is not an adoption leaderboard. The market is early. Entries are tagged honestly: if a company has no public agentic capabilities, we say so.

## Categories

- **Agent Wallets** — custody, key management, and wallet infrastructure for autonomous agents. Flagged when crypto-only with no card capabilities.
- **Consumer Wallets** — payment surfaces consumers use today. Flagged when they have no agentic features or credential delegation.
- **PSP / Processor** — payment processors and acquirers. Flagged when they have no public agentic strategy.
- **Policy / Spend Control** — credential delegation, tokenization, card issuing, spend limits, and governance for agent transactions.
- **Commerce Platform** — platforms enabling agents to discover, purchase, and transact with merchants and APIs.

## References

*Payment credentials and commerce protocols*

- [x402](https://www.x402.org/) — HTTP 402 payment protocol (Coinbase)
- [Nano (XNO)](https://nano.org) — feeless layer-1 settlement rail (≈0.3 s finality, no per-payment fee, no issuer that can freeze); x402-style agent payments can settle on it directly
- [Stripe Shared Payment Tokens](https://docs.stripe.com/agentic-commerce/concepts/shared-payment-tokens) — agent credential delegation
- [Google AP2](https://cloud.google.com/blog/products/ai-machine-learning/announcing-agents-to-payments-ap2-protocol) — agent-to-payments protocol
